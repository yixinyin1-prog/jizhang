# 富财记（原「生活记账」）

本地优先的记账工具，一套代码全平台可用：Windows 桌面 APP、安卓 APK（都已打包好），iPhone / iPad / Mac 走 PWA（苹果规定 iOS 应用必须用 Mac+Xcode 签名，Windows 上无法打包）。数据保存在设备本地，离线可用，不依赖任何服务器。

## 1.6.1 修复

- **删账户会让转账的钱凭空消失**（自检发现）：删掉一个「被转入过」的账户时，
  转账的转入方被置成 null，转出方扣了钱却没人收 —— 实测 3000 元蒸发，
  连「账户总额 == 积蓄」这条核心恒等式都破了。
  改为把转账两端重指到默认现金账户；并给默认账户加了兜底，
  让指向已删账户的孤儿转账（比如从老备份导入的）也能被认领。

## 功能

- **⚡ 智能记账**：一句话记一天 `早餐 3，地铁 4，午饭 16.8，加油 200，红包入 1.5`
  自动拆成多笔、识别收/支、计算 `8.31+7.84=16.15` 这类表达式、按关键词自动归类
- **🏷️ 自定义分类**：按钮网格排列，点开就能改名称/图标/颜色/关键词，并看到该分类的最近记录；
  支持**批量添加**（一行一个，可带 emoji 图标和关键词）
- **💼 资产核算**：积蓄、负债、债权、净资产四本账。借入/还款/借出/收回四类往来款单独核算；
  「真实收支」= 剔除往来款后的口径，与你原表的「支出合计」完全一致
- **📊 统计**：日/周/月/年 × 扇形/柱形/折线三种形态；收支平衡图；负债图谱；
  年视图另有「分类 × 月份」矩阵图、积蓄负债走势、每月结余正负柱（对标你原表那几张图）
- **📈 对比**：年度总览、月度对比、分类对比（**全部分类**矩阵 ↔ **单项细看**自由切换）
- **💾 数据**：导出 Excel（4 张工作表）/ CSV / JSON / 图谱 PNG；
  导入会**自动认格式**——你原来的手写账单（每月一张表）和本 APP 导出的表格都能直接吃
- **🎨 主题**：6 套低饱和配色（含夜幕石墨），全局生效
- **⏰ 自动备份**：**改完就备**（有改动就在退出时存一份，推荐）＋ 每天定点备份，位置/时间/保留份数都可改

### 自动备份的行为说明
两条保险叠加：
1. **改完就备（推荐，默认开）**：只要账目有改动，电脑版在**关闭程序时**、手机/网页版在**退出或切到后台时**自动存一份。
2. **定时备份**：每天到点再备一次；错过的（比如那天没开 APP）会在下次打开时自动补做。

各平台不申请后台常驻权限，所以行为一致。备份文件名精确到分钟，同一分钟内的多次备份会覆盖同名文件。备份位置：

| 平台 | 位置 |
|------|------|
| 电脑版 | 任意文件夹（「选择文件夹」指定），默认「文档/生活记账备份」 |
| 安卓版 | 手机「文档/生活记账备份」，可被文件管理器/网盘同步看到 |
| Mac / 浏览器 + Chrome/Edge | 授权后写入所选文件夹 |
| **iPhone / iPad / Safari** | **做不到自动备份**，改为到点提醒你手动存到「文件」/ iCloud 云盘 |

### 资产与负债怎么用
1. 「数据」页填三个期初值（开始记账**之前**的家底）：
   - **期初积蓄** = 手头有的钱（存款＋余额宝＋现金）
   - **期初负债** = 欠着的钱（花呗/分付/信用卡已用额度）
   - **期初债权** = 别人欠你的
2. 之后记账时，"借 500""借款 500"归到「借入款项」，"还 500""还款 500"归到「还款」
3. 积蓄 = 期初积蓄 ＋ 累计收入 − 累计支出　｜　负债 = 期初负债 ＋ 累计借入 − 累计还款
   净资产 = 积蓄 ＋ 别人欠我 − 我欠别人
4. 分类的往来款属性可在「分类」页点开任意分类修改

> 若负债余额显示「净还 XXX」，说明记录到的还款比借入多（早期数据常见：用花呗直接付款时没写"借"，只在还款时写了"还"），把期初负债填上即可。

### 导入你原来的 Excel 账单
**直接把原始 .xlsx 选进来就行**：APP →「数据」→「选择文件」→ 选 `25年生活账单.xlsx`。
会自动识别「每月一张表、一行一天」的格式、从文件名认出年份、逐日拆分文本并自动归类。

原理与注意：
- 解析结果与原表「支出合计 / 入账合计」有出入时，自动补一笔「导入校准」，保证每天总额和原表一致
- 原表的合计**不含还款/借款**，所以校准也只跟非往来款部分对账（对应 APP 里的「真实支出 / 真实收入」）
- 已有记录的日期自动跳过，可放心重复导入
- 「汇总表格」这类非月份表会自动忽略
- 认不出年份时会弹窗问你

> 实测 `25年生活账单.xlsx`：12 张月份表全部读入，其中 9 个月与原表汇总分毫不差。
> 另外 3 个月的差异是**原表自己**的「汇总表格」那一行和它自己的逐日行对不上（11月差 1200、9月差 88.28、2月差 131.34），APP 以逐日记录为准。

（`tools/convert_xlsx.py` 仍保留，可一次把多个年度表转成 `data/history.json`，但日常已用不上）

### 多设备同步
靠备份文件：「数据」→「导出备份」→ 传到另一台设备 →「选择文件」导入。

## 说明

- 数据存于本地 localStorage，**请开着自动备份**；清除应用数据会清掉账本
- 默认分类是通用款（餐饮、通勤、居住……），个人化的分类请用「分类」页的**批量添加**一次加好
- 「借 N」这种写法按**借入**处理（依你原表的用法：借完随即还掉相近金额，是花呗/分付的循环额度）；
  借给别人请写「借给 X」
